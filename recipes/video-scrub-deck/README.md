# Video Scrub Deck

## Use when

The page is presented as a sequence and exact copy states must align with exact visual states.

## Build

1. Define approved pause points.
2. Render or edit short scrub clips.
3. Encode frequent-keyframe and all-intra candidates.
4. Test real `currentTime` response in Chrome.
5. Load the first clip on intent and later clips near transitions.
6. Keep opening copy in one source of truth.
7. Provide Next and Previous controls when the experience is guided.
8. Build a complete reduced-motion version.
9. Verify range requests and reverse travel.
