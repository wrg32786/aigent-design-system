# Production Recipes

Recipes join direction, asset production, runtime selection, and QA. They are not generic components.

| Recipe | Use it when |
| --- | --- |
| `video-hero` | One cinematic shot carries the first viewport |
| `interactive-3d-object` | The visitor must inspect or manipulate a product |
| `video-scrub-deck` | Copy and media must land on approved scroll beats |
| `spline-scroll-scene` | A visually-authored 3D environment carries the page |
| `remotion-hero-loop` | One code-driven composition must render multiple web variants |

Every recipe requires a project context, an asset brief, provenance, a mobile state, reduced motion, and browser verification.
