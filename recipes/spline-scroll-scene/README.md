# Spline Scroll Scene

## Use when

A visually-authored interactive environment can carry the page without the cost of custom WebGL engineering.

## Build

1. Define one focal point and one camera progression.
2. Build and optimize the Spline scene.
3. Verify the plan/export requirements.
4. Add it behind complete semantic content.
5. Map scroll through a small shared state layer.
6. prevent touch interaction from blocking page navigation
7. create a poster and reduced-motion state
8. test mobile loading, GPU cost, and crop

Read `skills/spline-web-scene/SKILL.md`.
