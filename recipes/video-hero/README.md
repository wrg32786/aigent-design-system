# Video Hero

## Use when

A single cinematic shot establishes the product world and creates useful depth behind a clear offer or artifact.

## Build

1. Complete `creative-production/briefs/hero-video.md`.
2. Source, generate, or render the master.
3. Edit one desktop and one mobile composition.
4. Encode web MP4/WebM and extract a poster.
5. Record the manifest.
6. Use `<video muted playsinline>` with a poster and deliberate preload.
7. Keep the heading and action complete without playback.
8. Run asset, design, and browser checks.

## Avoid when

- the shot does not reinforce the page
- a still establishes the world equally well
- important meaning exists only in motion
- the page downloads the video before the user can use the content
