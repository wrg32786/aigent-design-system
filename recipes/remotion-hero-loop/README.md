# Remotion Hero Loop

## Use when

A code-driven composition must produce desktop, mobile, poster, and campaign variants from the same visual system.

## Build

1. Complete the hero-video brief.
2. Create an isolated Remotion project.
3. Define explicit props for text, palette, media, duration, and aspect ratio.
4. Render clean masters.
5. Encode final web variants with FFmpeg.
6. record the composition version and output manifest
7. integrate the outputs as ordinary web media
8. verify loop seam, poster, mobile crop, and reduced motion
