# Interactive 3D Object

## Use when

Inspection, configuration, material choice, hotspots, or object state is part of the product story.

## Build

1. Complete `creative-production/briefs/interactive-3d-object.md`.
2. Source or generate and license the model.
3. Clean it in Blender.
4. Export and optimize GLB.
5. Test with `model-viewer`.
6. Escalate to Three.js only for a requirement `model-viewer` cannot meet.
7. Create poster and mobile fallbacks.
8. Record the manifest and run checks.

## Avoid when

A turntable video, image sequence, or still gives the visitor the same understanding.
