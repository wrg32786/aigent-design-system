# Inspiration

Use inspiration to expand the design space, not to outsource the design decision to one existing website.

## Workflow

```text
CAPTURE → EXTRACT → ASSIGN → TRANSFORM → MAP → BUILD → AUDIT
```

1. Run `design-forensics` on each reference.
2. Use at least two references for whole-surface work; three is preferable when structure, type/material, and motion/media all matter.
3. Build the reference matrix before code.
4. Limit each source to two dimensions.
5. Record excluded expression and required transformations.
6. Map to existing AIgent patterns before creating new runtime code.
7. Produce original assets and copy.
8. Run `inspiration-originality-audit` after implementation.

## Good request

```text
Use A for its pinned chapter structure, B for editorial type density,
and C for the product-object reveal. Preserve our brand. Replace the
section order, typefaces, palette, assets, copy, and animation timing.
Show the reference matrix before implementation.
```

## Bad request

```text
Clone this site but change the colors and logo.
```

If the user asks for a near-exact clone, redirect to extracting the underlying principles and producing an original target-specific direction.
