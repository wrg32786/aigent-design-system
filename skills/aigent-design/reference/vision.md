# Vision and structured critique

Use AIgent Vision after Resolve has rendered the complete surface.

```text
resolve → vision prepare → open every capture → write structured review → vision check → vision finalize
```

The agent must inspect both original and annotated desktop, tablet, mobile, and reduced-motion images. Numbered `E###` overlays map visible findings to selectors and computed styles in the element map.

Review all twelve dimensions: product clarity, hierarchy, composition, typography, color/material, motion/media, interaction, product specificity, originality, responsive quality, trust/usability, and finish.

Every finding needs visible evidence, a bounded repair, relevant element IDs, a suspected shared owner when possible, and a preservation contract. Mechanical checks remain factual evidence; visual review supplies product and aesthetic judgment. Neither replaces the other.

Completion requires a passing combined report, not only a passing mechanical score.
