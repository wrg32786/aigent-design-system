# Craft Floor

Load immediately before implementation or final review.

## Must pass

- first viewport makes the offer, artifact, or task clear
- real proof appears early
- squint test reveals reading order
- body text meets WCAG AA and comfortable measure
- layout has deliberate tight and generous spacing
- one focal motion system carries the surface
- all interaction states required by the task exist
- mobile is recomposed
- reduced motion preserves meaning
- media has loading, poster, failure, and offscreen behavior
- asset rights and attribution are resolved
- no credentials, signed URLs, private records, or invented claims
- browser checks pass with real content

## Refuse by default

The brief can earn most devices. Habit cannot.

- identical icon-heading-text cards as the entire page
- nested cards
- eyebrow above every heading
- section numbers without meaningful sequence
- gradient text as generic emphasis
- pure black or arbitrary gray disconnected from the world
- decorative glass without valuable media behind it
- glow around inactive surfaces
- mono as a costume for technical
- floating 3D objects with no narrative or task
- repeated fade-up reveals
- bounce and elastic easing without physical reason
- system display fonts on a brand-defining experience
- modal as the first answer
- component-library defaults left visually untouched

## Final evidence

Run the relevant commands:

```bash
npm run registry
npm run intelligence
npm run assets
npm run catalogs
npm run audit -- <target>
npm run smoke
npm run capture
```

Use the eval rubric for release candidates. Deterministic checks are a floor. A human or capable visual reviewer must still judge product specificity, composition, and craft.
