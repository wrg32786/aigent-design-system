# Skills

Install only the skills relevant to the project. `cinematic-studio` is the umbrella router.

## Full production

| Skill | Owns |
| --- | --- |
| `cinematic-studio` | Direction → production → build → QA routing |
| `cinematic-web-director` | Product context, surface mode, visual direction |
| `creative-asset-director` | Asset medium, source, brief, and production route |
| `video-asset-pipeline` | Website video, posters, mobile and scrub exports |
| `web-3d-asset-pipeline` | 3D sourcing, Blender cleanup, GLB optimization |
| `asset-provenance-audit` | Rights, attribution, manifests, secret safety |
| `cinematic-site-qa` | Final browser and production QA |

## Runtime and motion

| Skill | Owns |
| --- | --- |
| `gsap-scroll-choreography` | Coordinated scroll and scene timelines |
| `threejs-web-scene` | Live Three.js and React Three Fiber scenes |
| `spline-web-scene` | Spline authoring, embedding, optimization |
| `remotion-web-assets` | Programmatic rendered web media |
| `video-scrub-deck` | Guided and free-scroll video decks |

## Existing page systems

| Skill | Owns |
| --- | --- |
| `modular-scroll-page` | Brand-neutral starter |
| `cinematic-asset-gallery` | Neutral resource/gallery system |
| `aigent-3d-scroll-system` | The AIgent 3D and deck patterns |
| `aigent-landing-page-polish` | The AIgent conversion and polish rules |
| `aigent-asset-gallery-system` | The AIgent-branded gallery pattern |

The `aigent-*` skills are intentionally brand-specific. New outside brands should start with the neutral skills.
