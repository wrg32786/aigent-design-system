# Aigent skills

## Normal install

From the repo you want Claude Code to design:

```bash
npx github:wrg32786/aigent-design-system install
```

The installed `aigent-design` skill is the normal entry point. Users should speak naturally; Claude routes to specialist knowledge internally.

## Main router

| Skill | Owns |
| --- | --- |
| `aigent-design` | brief → direction → inspiration → production → build → Taste → Resolve → Vision → polish |

## Inspiration

| Skill | Owns |
| --- | --- |
| `design-forensics` | URL, screenshot, motion, and structured-reference evidence → Design DNA |
| `reference-synthesis` | reference matrix, transformations, pattern mapping, and influence ledger |
| `inspiration-originality-audit` | source dominance, copy overlap, weak transformation, and publication review |

## Quality

| Skill | Owns |
| --- | --- |
| `design-resolver` | rendered evidence → ranked root-cause repair → mechanical gate |
| `visual-design-critic` | annotated captures → structured visual critique → visual completion gate |
| `cinematic-site-qa` | final browser, asset, and production QA |

## Existing page-system skills

| Skill | Owns |
| --- | --- |
| `modular-scroll-page` | brand-neutral cinematic starter |
| `cinematic-asset-gallery` | neutral resource and gallery system |
| `aigent-3d-scroll-system` | Aigent 3D and deck patterns |
| `aigent-landing-page-polish` | Aigent conversion and polish rules |
| `aigent-asset-gallery-system` | Aigent-branded gallery pattern |

The `aigent-*` specialist skills are brand-specific. Outside brands should enter through `aigent-design`, inspect their own product and references, and preserve their visual authority.

Advanced contributors can invoke specialist skills directly. Normal users should not need to know this list exists.
