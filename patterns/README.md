# Ready-to-use patterns

These are framework-neutral interaction systems, not decorative snippets. Each pattern ships as a small CSS/JavaScript pair and keeps the page usable when JavaScript or an optional renderer fails.

| Pattern | Job | Runtime |
| --- | --- | --- |
| `guided-deck` | Controlled chapter navigation for sales decks and demos | Native JavaScript |
| `command-palette` | Searchable keyboard command surface for product UI | Native `<dialog>` |
| `focus-reveal` | Bounded material reveal for important content | IntersectionObserver |
| `scene-stage` | Publish global, chapter, and local scroll progress | Native JavaScript |
| `object-stage` | Progressive loading contract for Spline, model-viewer, or Three.js | Native JavaScript + chosen renderer |

Install patterns through the root GitHub registry or copy the directory. Keep only the pattern the page actually uses.
