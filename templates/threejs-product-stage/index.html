Purpose

Use live 3D for inspection, configuration, procedural state, geometry, lighting, or direct manipulation—not for an object that only floats.

Load

Initialize near the viewport, cap device pixel ratio, avoid blocking the first useful view, and surface a clear failure state.

Pause

Stop the render loop when the stage is offscreen or the document is hidden. Kill work the visitor cannot see.

Fallback

Provide a complete poster or CSS state, preserve copy and action, and remove spatial travel under reduced motion.
