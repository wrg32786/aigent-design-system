Cinematic System

Experience surface · native CSS + JavaScript

A cinematic page needs a point of view.

This starter separates the reusable mechanics from the visual world. Keep the contract. Replace the art direction.

Use the system Read the guide
01

Define the world before the effects.

Name the audience, the action, the proof, and the visual habits you refuse. A palette without that context is decoration.

  • ProductWho is here, what must they understand, and what should they do?
  • ModePersuade, operate, read, or experience. The surface decides the priority.
  • WorldChoose type, material, composition, color, and one signature interaction from the subject—not from a template category.
  • Anti-referenceWrite down what would make a polished result feel generic or wrong.
02

Compose with layers, not a forked template.

Tokens own the visual roles. The scene owns the media. Motion publishes a few CSS variables. Content remains ordinary HTML. 

import {
  mountScrollScene,
  mountReveals
} from "/modules/motion.js";

mountScrollScene({
  progressMultiplier: 1.35,
  scale: 0.48,
  rotation: -18,
  translateY: -36
});

mountReveals();
03

Verify the result, not the intention.

A dramatic page still has to explain itself, work by keyboard, fit real copy, and remain complete with motion reduced.

  • First viewportThe offer, artifact, or task is obvious within seconds.
  • HierarchyOne focal point leads. Supporting content does not compete with it.
  • MotionOne authored moment carries the page; repeated entrance effects stay quiet.
  • AccessContrast, focus, touch targets, semantic HTML, and reduced motion survive the spectacle.

Start neutral. Earn the spectacle.

The live AIgent sites show one committed world. This starter exists so the next site can commit to a different one.
