01 / Separate the layers

Content, theme, scene, motion.

Each layer has one job. Copy can change without touching animation. A new palette needs token overrides, not a CSS rewrite.

Tokens

Semantic color, type, surface, radius, spacing, and motion variables.

Primitives

Small classes for shells, panels, buttons, labels, and theme controls.

Modules

Native scroll progress, scene transforms, reveals, and theme switching.

02 / Configure, do not fork

One motion engine. Different worlds.

The scene reads CSS variables. Use the same module with Spline, video, a frame sequence, WebGL, or a plain CSS object. 

import {
  mountScrollScene,
  mountReveals
} from "/modules/motion.js";

mountScrollScene({
  progressMultiplier: 1.5,
  scale: 0.9,
  rotation: -64
});

mountReveals();
