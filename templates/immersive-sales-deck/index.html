Opening / The proposition

Turn the sequence into the pitch.

A ready-to-adapt guided deck for products that need atmosphere, proof, and a clear decision—not another stack of disconnected slides.

Why guided

The presenter controls timing. Every move lands on a complete visual and verbal state.

Problem / The default

Most decks show. Great decks prove.

A cinematic surface only works when the visual sequence and the argument share one structure.

Refuse

Uncontrolled scroll, duplicate copy, decorative metrics, and media transitions that finish after the point has passed.

Mechanism / The system

Direct. Produce. Build. Verify.

  • DirectResolve audience, proof, visual world, structure, and one signature motion.
  • ProduceSource or create the media the argument actually needs.
  • BuildUse the lightest runtime that carries the interaction.
  • VerifyCheck rights, accessibility, mobile behavior, and the rendered result.
One chain

The design and the media are directed together instead of assembled as unrelated effects.

Proof / Review loop

The browser gets the final vote.

  • TasteFlags repeated generated-design defaults in source.
  • ResolveMeasures runtime, responsive, focus, contrast, clipping, reduced motion, and related browser behavior.
  • VisionStructures the rendered visual review for a capable image-reviewing agent or human.

Operating model / Adaptation

Install the skill. Keep the product authority.

Aigent installs under the project skill directory, keeps project context separate, and uses package-backed tooling for browser QA and inspiration analysis.

Dependency rule

Native first. Existing modules second. Optional integration third. Custom runtime only after the requirement earns it.

Decision / Next action

Judge the output, not the pitch.

Install Aigent in a real repo, direct one meaningful surface, then compare the result against your normal Claude workflow.
