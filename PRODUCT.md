# Product

## Register

Open-source design system and agent operating layer for cinematic web work.

## Users

- Builders using Codex, Claude Code, Cursor, or another coding agent who want a stronger visual starting point than a generic generated landing page.
- Designers and developers who need reusable scroll, video, 3D, gallery, and presentation patterns without adopting a framework.
- The AIgent team, which uses this repository to preserve the design decisions behind `theaigent.xyz` and `tools.theaigent.xyz`.

## Purpose

The system turns design judgment into inspectable assets: semantic tokens, small motion modules, page templates, agent skills, production playbooks, and checks. A user should be able to keep the engineering contract while replacing the brand, media, composition, and tone.

## Success

A successful adopter can:

1. Open a working page in minutes.
2. Define a distinct product and visual world before styling.
3. Change the palette and typography without rewriting components.
4. Replace CSS art with video, Spline, frame sequences, or WebGL without rewriting content.
5. Ship a responsive, accessible result that does not look like The AIgent unless that identity was chosen deliberately.

## Proof

- `https://theaigent.xyz` is the primary **Persuade + Experience** showcase: a narrative descent with cinematic chapters and fixed instrumentation.
- `https://tools.theaigent.xyz` is the primary **Operate + Read** showcase: the same identity adapted into a useful, dense public vault.

These sites prove the system's taste and motion principles. They are not universal templates.

## Personality

Decisive, cinematic, practical, open.

The documentation should sound like a design director who can also maintain the code: specific, plainspoken, and willing to remove an effect that does not earn its cost.

## Anti-references

Do not drift into:

- a cyan clone of The AIgent for unrelated products
- generic dark AI marketing with neon gradients, floating orbs, and indiscriminate glow
- identical feature-card grids used as the whole page structure
- glass surfaces where there is no meaningful media behind them
- 3D objects that do not explain, orient, compare, or reward
- mono typography used as a costume for “technical”
- motion applied to every section because the animation library is available
- a framework or component abstraction introduced before two real pages need it

## Constraints

- Static HTML, CSS, and JavaScript remain first-class.
- Existing AIgent-branded templates must remain compatible.
- Accessibility, reduced motion, keyboard focus, and mobile layout are part of the design, not cleanup.
- Third-party references may inform principles; files are not vendored without license review and attribution.
