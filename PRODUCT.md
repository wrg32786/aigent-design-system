# Product

## Register

Open-source, agent-native cinematic web production system.

## Users

- Builders using Codex, Claude Code, Cursor, or another coding agent who want a stronger output than a generic generated landing page.
- Designers and developers who need reusable scroll, video, 3D, gallery, presentation, and media-production systems without adopting one framework.
- Solo operators and small teams that need to find, generate, clear, optimize, and ship visual assets without assembling the workflow from scratch.
- The AIgent team, which uses this repository to preserve the decisions behind `theaigent.xyz` and `tools.theaigent.xyz`.

## Purpose

The system turns design and production judgment into inspectable assets:

- product and design context
- semantic tokens
- motion modules
- page systems
- creative resource catalog
- asset briefs and pipelines
- optional runtime integrations
- agent skills
- provenance manifests
- performance budgets
- deterministic and browser checks

A user should be able to keep the engineering contract while replacing the brand, media, composition, and tone.

## Core loop

```text
Direct → Produce → Build → Verify
```

The system is incomplete if it recommends cinematic media but does not explain how to source, generate, render, clear, optimize, and deliver that media.

## Success

A successful adopter can:

1. Open a working page in minutes.
2. Define a distinct product and visual world before styling.
3. Select the lightest medium and runtime that carries the concept.
4. Find or generate an asset under understood rights.
5. Produce desktop, mobile, poster, and reduced-motion outputs.
6. Record provenance without exposing private information.
7. Replace CSS art with video, Spline, a frame sequence, model-viewer, or WebGL without rewriting content.
8. Ship a responsive, accessible page that does not look like The AIgent unless that identity was selected deliberately.
9. Regenerate or replace assets without reverse-engineering the page.

## Proof

- `https://theaigent.xyz` is the primary Persuade + Experience showcase.
- `https://tools.theaigent.xyz` is the primary Operate + Read showcase.

They prove the craft and motion principles. They are not universal templates.

## Personality

Decisive, cinematic, practical, open.

Documentation should sound like a design director who can maintain the code and the production pipeline: specific, plainspoken, and willing to remove an effect that does not earn its cost.

## Anti-references

Do not drift into:

- a cyan clone of The AIgent for unrelated products
- generic dark AI marketing with neon gradients, floating orbs, and indiscriminate glow
- an asset directory with hundreds of unqualified links
- a “free” recommendation that ignores commercial rights
- generated video or 3D treated as a finished web asset
- live Three.js where a poster, video, or model-viewer would work
- identical feature-card grids as the whole page structure
- glass without valuable media behind it
- mono typography as a costume for technical credibility
- motion on every section because a library is available
- all integrations installed in the root package
- framework or component abstraction before two real pages need it

## Constraints

- Static HTML, CSS, and JavaScript remain first-class.
- The neutral core remains dependency-free.
- Integrations are opt-in and isolated.
- Existing AIgent-branded templates remain compatible.
- Accessibility, reduced motion, focus, loading, failure, and mobile states are part of the design.
- Production assets require provenance and resolved rights.
- Source masters and private records stay out of the public repository.
- Third-party material is not vendored without license review and required attribution.
