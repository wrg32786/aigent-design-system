# Product

## Register

Open-source, installable, agent-native design and production system for immersive websites, cinematic decks, product interfaces, inspiration forensics, the media behind them, and the final render-repair-verification loop.

## Users

- Builders using Claude Code, Codex, Cursor, or another coding agent who want professional, product-specific design rather than generic generated pages.
- Designers and developers who need reusable website, deck, interface, video, 3D, gallery, motion, and inspiration systems without adopting one framework.
- Solo operators and small teams that need to study references, generate an original direction, find or create assets, and ship without assembling the workflow from scratch.
- The AIgent team, which uses this repository to preserve and extend the decisions behind `theaigent.xyz` and `tools.theaigent.xyz`.

## Core loop

```text
Shape → Inspire → Synthesize → Produce → Build → Resolve
```

The system is incomplete if it studies inspiration without recording evidence and transformation, recommends cinematic media without a production route, or claims completion without a passing Resolve gate, browser proof, and explicit visual review.

## Success

A successful adopter can:

1. Install a complete system in one command.
2. Define product truth and a distinct visual world before styling.
3. Inspect public references across desktop, tablet, mobile, interaction, media, and motion.
4. Convert evidence into Design DNA with explicit uncertainty.
5. Divide influence across at least three references so no source controls the result.
6. Record required transformations and excluded source expression.
7. Generate an inspectable layout, typography, motion, media, and runtime plan.
8. Use mature accessible primitives without inheriting unrelated visual languages.
9. Find or generate assets under understood rights.
10. Produce desktop, mobile, poster, reduced-motion, loading, and failure states.
11. Build a cinematic page, immersive sales deck, or trustworthy product interface.
12. Record provenance and influence without exposing private information.
13. Audit source dominance, copy overlap, accessibility, assets, and rendered behavior.
14. Run the ranked Resolve loop until no P0 or P1 issue remains and the mechanical gate passes.
15. Complete explicit visual review rather than treating a green report as taste.
16. Ship a result that makes sense without the references and does not look like The AIgent unless that identity was selected deliberately.

## Personality

Decisive, cinematic, practical, open.

Documentation should sound like a design director who can maintain the code and production pipeline: specific, plainspoken, and willing to remove an effect, component, dependency, or reference that does not earn its cost.

## Anti-references

Do not drift into:

- a clone command disguised as inspiration
- one reference controlling layout, type, palette, motion, interaction, and media
- third-party screenshots or extracted private pages committed to the public repo
- exact source copy, assets, marks, section order, type pairing, or keyframes
- a cyan clone of The AIgent for unrelated products
- generic dark AI marketing with neon gradients and floating orbs
- identical feature-card grids as the whole page structure
- component-library visual soup
- a huge menu of overlapping skills
- a “free” recommendation that ignores commercial rights
- generated video or 3D treated as a finished web asset
- live Three.js where a poster, video, or model-viewer would work
- decorative motion on every section
- all integrations installed in the root package
- benchmark scores that fabricate visual judgment
- documentation-only recipes presented as complete implementations

## Constraints

- Static HTML, CSS, and JavaScript remain first-class.
- The neutral runtime core remains dependency-free; Playwright is a development and QA dependency.
- Integrations and external components are opt-in and isolated.
- The public registry installs only declared files.
- Existing AIgent-branded templates remain compatible.
- Accessibility, reduced motion, focus, loading, failure, empty, error, disabled, and mobile states are part of the design.
- Production assets require provenance and resolved rights.
- Inspiration captures, source masters, and private records stay out of the public repository.
- Third-party material is not vendored without license review and required attribution.
- Inspiration similarity is a review heuristic, not legal advice.
- Mechanical Resolve passage never substitutes for explicit human or operating-agent visual judgment.
