What is actually shipped.

Direction

The core skill reads the existing repo, helps resolve the visual world, persists approved direction, and preserves unrelated work during scoped revisions.

Inspiration

Public references can be captured into Design DNA, divided across design dimensions, transformed, and reviewed for source dominance instead of treated as clone targets.

Browser QA

Resolve measures responsive behavior, focus, contrast, touch targets, clipping, runtime failures, reduced motion, and related mechanical evidence in Chromium.

No fake benchmark claim.

The examples above prove implementation craft, not that Aigent automatically beats every baseline. The repository now includes a fixed comparative protocol for baseline, Impeccable, and Aigent runs. Those results should be published only after the runs exist.

How you use it.

01
Install safely

Vendor files stay under the Aigent skill directory and are tracked by hash. Existing project authority is not replaced.

02
Direct the work

Ask Claude to use Aigent. It can inspect the repo, ask only high-leverage questions, and offer distinct directions before a large redesign.

03
Build in source

The real application remains the source of truth. Aigent does not create a second IDE or proprietary project shell.

04
Render and repair

Use Taste as a smell linter, Resolve as the mechanical floor, and Vision as a structured rendered-review protocol.
