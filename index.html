Reuse the decisions, not the skin.

Every new page begins with product context and a visual contract. The code then keeps five concerns separate.

  1. ContentProduct truth, copy, proof, links, and calls to action.
  2. ThemeSemantic color, typography, spacing, surfaces, and component roles.
  3. SceneCSS, images, Spline, video, frame sequences, or WebGL.
  4. MotionSmall modules that publish scroll and viewport state to CSS.
  5. TemplateA composition for one use case—not a universal page scaffold.
Taste rule

The AIgent palette is earned by The AIgent brand. Outside projects should inherit the system’s discipline, then choose their own visual world.
