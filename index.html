Aigent · agent-native design system

Turn Claude into your design team.

Install Aigent into a repo, open Claude Code, and describe what you want in normal language. Aigent gives Claude the design judgment, creative-production knowledge, browser QA, and visual-review loop to build polished websites, interfaces, decks, and immersive experiences.

One command inside your project npx github:wrg32786/aigent-design-system install

No second IDE.

Claude is the interface

Use the coding environment and subscription you already have. Aigent installs into the project rather than asking you to learn another application.

Aigent routes the expertise

You do not choose specialist skills. Claude infers when it needs inspiration, typography, motion, assets, Taste, Resolve, Vision, or publishing guidance.

The browser is ground truth

Aigent is designed to render, inspect, repair, and polish the real project rather than stop when code compiles.

How you use it.

01
Install

Run the one command in a local checkout or cloud development repo.

02
Open Claude

Start Claude Code in the same repo.

03
Describe the job

“Use Aigent to redesign this site. Help me figure out the direction before you build it.”

04
Let Aigent steer

Claude can ask for the audience, brand constraints, strongest proof, or a few designs you like when those answers would materially improve the result.

05
Build and refine

Choose or combine a direction, then talk normally: “make it bolder,” “fix mobile,” “add one memorable interaction,” or “run the full Aigent review.”
