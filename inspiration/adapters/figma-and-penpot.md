# Figma and Penpot Adapter

Use an editable design canvas only when human review or collaboration justifies the round trip.

## Recommended flow

```text
references → Design DNA → reference matrix → editable direction board → reviewed structure → implementation
```

The direction board should contain original compositions, target-brand type and color roles, asset briefs, motion sentences and explicit reference attribution. It should not trace screenshots or reproduce source assets.

Figma MCP can expose structured frames and components to an agent. Penpot is an open-source alternative with design-token and web-standard workflows. Both are optional; code-first remains the default.
