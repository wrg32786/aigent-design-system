# InspirationBench

InspirationBench compares three conditions with the same model, product brief, content, asset allowance, implementation time and viewport set:

1. no inspiration references
2. raw screenshots or URLs in the prompt
3. AIgent Design DNA, reference matrix and influence ledger

The benchmark is not a pixel-similarity contest. A successful result uses the correct ideas, transforms them, fits the product and remains original.

## Required evidence

- source records and capture dates
- model and prompt
- generated site
- target Design DNA
- influence ledger
- originality audit
- desktop, mobile and reduced-motion captures
- human review

## Human review

Reviewers score product clarity, specificity, hierarchy, typography, material, motion, media, responsive behavior, finish, correct inspiration extraction and originality.

The script may calculate mechanical evidence. It must never invent the human score.
