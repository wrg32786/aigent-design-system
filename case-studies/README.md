# Production case studies

These case studies separate transferable decisions from brand-specific execution.

| Surface | Mode | Transferable lesson |
| --- | --- | --- |
| `theaigent-home/` | Persuade + Experience | A long page can behave as one narrative journey when instrumentation, chapters, copy, and motion share a single model. |
| `tools-vault/` | Operate + Read | The same identity can become a dense utility surface by preserving type, signal color, and voice while replacing theatrical structure with direct access. |

Copy the reasoning and production contracts. Do not copy the brand skin, claims, or exact composition by default.
