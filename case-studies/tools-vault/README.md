# The AIgent Tools vault

**Live surface:** `https://tools.theaigent.xyz`

## Job

Help AI operators find useful repos, prompts, MCP servers, skills, evals, design assets, and operator kits quickly while understanding why each shelf matters.

## Structural thesis

The same AIgent identity becomes an index. The visitor is not asked to watch a story before accessing the material.

```text
orientation and access
→ one-line vault promise
→ direct shelf sequence
→ concise explanation
→ immediate open action
→ single unlock action for the whole collection
```

The surface is Operate + Read: stable wayfinding, direct category labels, dense useful content, and restrained motion.

## What is transferable

- familiar category navigation for a large curated collection
- direct labels before decorative framing
- one explanation and one action per shelf
- density created through rules, rhythm, and typography rather than a mosaic of cards
- one access model for the complete collection
- consistent language across categories

## What is brand-specific

- vault metaphor and operator language
- AIgent signal colors, type, and status chrome
- exact categories, counts, claims, and unlock flow
- relationship to The AIgent homepage and newsletter

## Interface contract

- navigation and search must remain usable before visual effects
- categories need stable names and predictable order
- empty, loading, locked, unlocked, and returning-user states need explicit behavior
- mobile navigation must preserve direct access to every shelf
- motion supports orientation and state; it does not delay access

## Extraction

Relevant reusable systems:

- `dense-vault` layout grammar
- `resource-vault` interface system
- `command-palette` and search patterns where the collection grows
- `cinematic-asset-gallery` skill
- `design-vault` registry item

## Do not copy

Do not use the vault metaphor or locked-email interaction for a collection that is public, small, or task-specific. Preserve the direct-access grammar and choose a metaphor from the target product's world.
