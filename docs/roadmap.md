# Roadmap

## Shipped foundations

- Aigent core skill: project-first art direction, approved-direction persistence, preservation contract, and package-backed tooling
- Inspiration Intelligence: URL/file forensics, Design DNA, multi-source synthesis, influence ledgers, and originality heuristics
- Design Intelligence: deterministic planner and curated layout/type/motion/interface systems
- Aigent Taste: source-level generated-design smell checks
- Aigent Resolve: ranked multi-viewport browser evidence and mechanical completion gates
- Aigent Vision: structured rendered-review protocol for a capable multimodal agent or human
- Agent-native product: Claude Code remains the interface; no separate Desktop/Studio product
- consumer-safe install ownership: default install writes vendor skill files only, records hashes, preserves modified files, and supports uninstall
- project-safe initialization: `.aigent/project-context.md` is opt-in and never replaces root project authority
- explicit Chromium setup and doctor path for browser-backed features

## Now

Do not add another major capability until these are complete:

1. Run the exact public GitHub install path across clean plain HTML, Vite, React, Next.js, Astro, Windows, macOS, and cloud-development fixtures.
2. Run the comparative suite in `evals/comparative/` for baseline, Impeccable, and Aigent with at least three independent runs per brief.
3. Publish the complete results, including failures and mediocre runs rather than only the best output.
4. Build three real before/after case studies from those runs: bright consumer, dense operations UI, and cinematic launch.
5. Rebuild the public landing page around those actual outputs once they exist.
6. Add reviewed visual-regression baselines for canonical examples.
7. Move installation from mutable GitHub-head execution to versioned immutable distribution after the consumer matrix is green.

## After proof

- add high-value interface or immersive systems only when a real project demonstrates the gap
- add an owned optimized model-viewer reference
- add one complete Remotion composition and rendered output
- add one owned Spline scene with loading and failure proof
- consider additional coding-agent adapters without forking the core design doctrine
- consider a public built-with-Aigent gallery

## Later research

- optional local SigLIP/DINOv2 retrieval for large reference libraries
- diversity-aware reference recommendation
- Figma/Penpot direction-board round trips only when they improve the coding-agent workflow
- automated WebGL performance tiers and context-loss verification

## Product rule

Do not rebuild an IDE, project manager, authentication shell, or visual editor around Aigent. The coding agent is the interface. Do not confuse a new feature with proof that the existing product works. The next unit of progress is evidence.
