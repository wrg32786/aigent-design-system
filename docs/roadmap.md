# Roadmap

## Shipped

- semantic `ds-*` token API with five theme presets
- backward-compatible AIgent theme aliases
- dependency-free modular scroll starter
- Spline, gallery, and video-scrub showcases
- native motion helpers
- product and design context contracts
- neutral cinematic design-director skill
- deterministic design audit and browser smoke test
- live production proof through The AIgent and The AIgent Tools

## Next

1. Migrate the three legacy showcases from hard-coded AIgent values to the semantic token API, simplest template first.
2. Extract a motion pattern only after the same intent appears in at least two production pages.
3. Add lightweight visual-regression captures for the root dossier and modular starter.
4. Add one owned frame-sequence example when a real project needs that renderer.

## Not Yet

- a framework wrapper
- a component package
- a CLI scaffold
- an installer

Those should exist only after repeated outside use proves a stable contract. Static HTML, CSS, and JavaScript remain the source of truth.
