## Asset sources

The curated source of record is:

```text
creative-production/catalog.json
```

It contains official URLs, license posture, cost tier, use cases, cautions, and verification dates.

## Intake rule

For every external reference:

1. Save the official source.
2. Verify license and redistribution rights.
3. State the transferable lesson.
4. Implement the smallest original token, module, recipe, skill, or QA rule.
5. Do not vendor code, assets, prompts, models, or skill files without explicit license clearance.
6. Update `THIRD_PARTY.md` when material is included directly.
7. Add a verification date for volatile plan or license information.
