## Intake rule

For every external reference:

1. Save the official source.
2. Verify license and redistribution rights.
3. State the transferable lesson.
4. Implement the smallest original token, pattern, recipe, planner record, skill, or QA rule.
5. Prefer external installation over vendoring when the source already has a maintained distribution path.
6. Do not copy code, assets, prompts, models, visual identities, or skill text without explicit clearance.
7. Update `THIRD_PARTY.md` when material is included directly.
8. Add a verification date for volatile plan or license information.
