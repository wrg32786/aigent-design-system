# Product Brief

## One-line promise

Give builders and coding agents one open system to direct, produce, build, and verify cinematic websites instead of assembling design taste, media sourcing, 3D, video, motion, and QA from separate references.

## Why it exists

Coding agents can produce functional pages quickly, but high-end visual work still fails at several connected steps:

- the product and surface mode are not defined
- the page defaults to generic generated design
- the hero video or 3D asset does not exist
- source and generation rights are unclear
- raw media is not optimized for the browser
- a heavy runtime is selected by habit
- mobile and reduced motion are afterthoughts
- the result is judged from source instead of the real browser

This repository preserves the full production loop.

## Audience

- solo founders and operators
- coding-agent users
- frontend developers
- creative technologists
- designers building scroll, video, 3D, gallery, and presentation experiences
- small teams that need clear free and affordable production routes

## Product layers

1. Product and design context.
2. Creative resource and integration catalogs.
3. Asset briefs, source selection, generation, rendering, and optimization.
4. Static page systems and optional runtimes.
5. Agent skills for every stage.
6. Provenance, budgets, deterministic checks, and browser QA.

## Success criteria

- A new user can open a working page in minutes.
- An agent can determine the correct surface mode and medium.
- A user can find a source or production route without guessing about basic rights.
- A generated or sourced asset enters a real web pipeline.
- The core remains useful without installing a framework or animation library.
- Rich integrations are available when earned.
- Every page has mobile, reduced-motion, loading, and failure behavior.
- Production media has a manifest.
- The AIgent visual identity remains recognizable but optional.
