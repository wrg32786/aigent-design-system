# GSAP

Use GSAP for coordinated timelines: pinned chapters, video scrub state, scene handoffs, and copy that must land on exact visual beats.

```bash
npm install gsap
```

Start with native CSS and `modules/motion.js`. Add GSAP when one shared timeline is materially simpler than several independent observers.

Read:

- `skills/gsap-scroll-choreography/SKILL.md`
- `skills/video-scrub-deck/SKILL.md`
- `docs/cinematic-scroll-deck-playbook.md`

The official GSAP agent-skills repository is a useful tool-specific reference. This repository's skill stays focused on art direction, page state, and production QA rather than duplicating GSAP documentation.

Current official guidance states that GSAP and its plugins are free, including commercial use. Recheck the official standard license before distribution.
