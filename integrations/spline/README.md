# Spline

Use Spline for rapid visual 3D authoring when a designer or agent needs to manipulate the scene directly.

Possible integration:

```bash
npm install @splinetool/runtime
```

Or use the documented viewer export when the embed fits the project.

Before production:

- verify the current plan permits the required watermark-free export
- reduce scene complexity
- avoid expensive post-processing by default
- test touch interaction
- provide a poster
- prevent the scene from blocking content or controls
- confirm loading behavior on a real phone
