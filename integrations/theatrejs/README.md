# Theatre.js

Use Theatre.js when a complex Three.js camera or object sequence benefits from visual keyframe authoring.

```bash
npm install @theatre/core @theatre/studio
```

Keep Studio in the authoring workflow. Ship only the production pieces the final experience needs.

Use GSAP for a short inspectable timeline. Use Theatre.js when the visual timeline itself is the production tool.

Read `skills/threejs-web-scene/SKILL.md`.

Theatre.js Core and Studio have different licenses. Review the current repository license details before distribution.
