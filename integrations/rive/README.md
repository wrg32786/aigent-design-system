# Rive

Use Rive for interactive 2D vector animation driven by real product state.

```bash
npm install @rive-app/canvas
```

Good uses:

- input and loading state
- stateful diagrams
- compact branded interaction
- a control whose animation communicates state

Avoid using it as a decorative animation layer behind unrelated content.

The web runtime is open source; editor and export access follow the active Rive plan. Verify the current plan before production.
